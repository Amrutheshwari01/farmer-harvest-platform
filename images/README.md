# Images Directory

This directory contains images used in the farmer-harvest-platform.

## Required Images

### mic-icon.png
Replace the placeholder file with your cucumber microphone image.

The image should be:
- PNG format
- Approximately 64x64 pixels or 128x128 pixels for good quality
- Transparent background preferred
- The cucumber microphone design as shown in the reference image

## How to Add Your Image

1. Save your cucumber microphone image as `mic-icon.png` in this directory
2. Make sure the file name is exactly `mic-icon.png` (case-sensitive)
3. The image will automatically be served by the Flask application
